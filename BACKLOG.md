## 📋 BACKLOG

### Версия 2.0

**Дистиллированные модели:**
- Замена `qwen2.5:7b` на дистиллированные версии (например, `DeepSeek-R1-Distill-Qwen-7B`).
- Вынос имён моделей в `.env` (уже заложено).

**Fallback на платные API:**
- Основной провайдер: Ollama (локально).
- Fallback: DeepSeek API / OpenRouter при недоступности домашнего ПК.
- Флаг `ALLOW_PAID_FALLBACK=false` по умолчанию.
- Логирование стоимости API-запросов.
- Переключатель провайдера в GUI.
- Уведомление при переключении: «Домашний ПК недоступен, использую DeepSeek, потрачено ~0.5₽».

**Рефлексия — режим `batch`:**
- Вся сессия одним запросом.
- Без классификации на лету.
- Без порога 3 сообщения.
- Реализация в `core/reflection.py` через флаг `REFLECTION_MODE`.

**Веб-чат:**
- Реализация после Этапа 8.
- Контекст проекта: ТЗ + описание + отчёты.

**Дублирование БД:**
- Синхронизация между ноутбуком и домашним ПК.
- Только когда появится необходимость.

**Плагинная система:**
- Для источников идей и внешних интеграций.

**Этап 5.5: Система проверки иерархии задач**
- Галочка на подзадаче → проверка этой подзадачи.
- Галочка на big_block → проверка всех подзадач внутри.
- Кнопка «Проверить проект» → проверка всех задач снизу вверх.
- После всех проверок → «Возможно слияние».
- После слияния → проверка, что всё работает.
